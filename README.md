# CS3264 — Foundations of Machine Learning

Course website for **CS3264, Semester 1 AY2026/27**, School of Computing,
National University of Singapore.

Live at **<https://haroldsoh.com/cs3264>**.

Static HTML and CSS — no build step, no dependencies. `index.html` is the whole
site; `slides/` holds the lecture decks and `notes/` past years' collaborative
notes.

Course content by Harold Soh and the CS3264 teaching team. The site and course
materials were built with the help of large language models, principally Claude.
